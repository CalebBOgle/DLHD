# DLHD.py
An all encompassing script that can be used to train the independent component networks (DS,CNN) or the full DLHD architecture (with or without pretraining 
the component networks). 

# Plotting.py 
An interactive notebook that demonstrates how figures 3-7 were generated in the paper, and can be used to create new figures. It also contains the code used 
to compute the statistics on the "naive" combination mentioned in Section 3.3 .

# predicted_values 
Contains predicted parameter values and log-uncertainties from each trial.

# true_values 
Contains the true parameter values from each trial. 

# NN_configs
Contains pytorch configurations of the neural networks used in each trial.

# databases
Contains Optuna databases from each trial.

# figures
Contains figures 3-7 in paper.
